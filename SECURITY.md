# Politique de sécurité

## Signaler une vulnérabilité

**N'ouvrez pas d'issue publique** pour une faille de sécurité.

Utilisez le signalement privé de GitHub : onglet **Security** → **Report a vulnerability**.

Indiquez si possible :

- une description du problème et son impact ;
- les étapes pour le reproduire ;
- la version ou le commit concerné.

Nous nous efforçons de répondre sous 7 jours.
